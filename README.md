# GitHub Pages test destination

This public repository is a non-sensitive destination for documentation deployment tests.

- `main` keeps this README.
- `gh-pages` contains only the public static site, initially a placeholder `index.html` and an empty `.nojekyll` file.
- GitHub Pages is configured to publish from `gh-pages` at `/(root)`, without a custom domain.

The placeholder is not a devdocs deployment result. Publishing a generated documentation site is a separate, explicitly approved step.
